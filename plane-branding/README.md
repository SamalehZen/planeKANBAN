## Usage Guidelines

### Logo Usage
1. **Minimum Size**: Logo should not be smaller than 24px height
2. **Clear Space**: Maintain padding equal to half the logo height on all sides
3. **Do Not**: Stretch, rotate, or modify the logo proportions
4. **Backgrounds**: Use white logo on dark backgrounds, black or blue on light backgrounds

### Color Usage
- Use Plane Blue (#3F76FF) as the primary accent color
- Maintain sufficient contrast for accessibility (WCAG AA minimum)
