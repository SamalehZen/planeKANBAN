## ✨ Features

- 📋 **Work Items** - Manage tasks with rich text editor
- 🔄 **Cycles** - Sprint management with burn-down charts  
- 📦 **Modules** - Organize projects into manageable parts
- 👁️ **Views** - Custom filters and saved views
- 📝 **Pages** - Documentation with AI capabilities
- 📊 **Analytics** - Real-time project insights
- 🎤 **Speech-to-Text** - Voice input for quick task creation
- 🤖 **AI Summarize** - Automatic content summarization

## 🛠️ Tech Stack

- **Frontend**: React Router, TypeScript, Tailwind CSS
- **Backend**: Django, Python
- **Database**: PostgreSQL (Neon)
- **Storage**: Cloudflare R2
- **Hosting**: Render
