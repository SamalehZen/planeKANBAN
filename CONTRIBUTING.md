# Contributing to HyperPLANE

Thank you for your interest in contributing to HyperPLANE!

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Install dependencies with `pnpm install`
4. Start development with `pnpm dev`

## Submitting Issues

Before submitting a new issue, please search the [issues](https://github.com/SamalehZen/planeKANBAN/issues) tab.

You can open a new issue with this [issue form](https://github.com/SamalehZen/planeKANBAN/issues/new).

## Pull Requests

1. Create a new branch for your feature
2. Make your changes
3. Test thoroughly
4. Submit a pull request

## Code Style

- Use TypeScript
- Follow existing code patterns
- Run `pnpm check` before submitting
